# Registro de solicitudes y soluciones

## 1. Restauracion de `main.py`

**Solicitud:** Restaurar `main.py`.

**Solucion:** Se comprobo que el archivo estaba vacio y sin historial Git. Se recupero la copia disponible en el historial local de VS Code.

## 2. Creacion de la clase `Agente`

**Solicitud:** Crear una clase para un agente de Groq que recibiera su comportamiento, leyera `GROQ_API_KEY` con `os.getenv()` y comenzara un historial con un mensaje `system`.

**Solucion:** Se creo `agente.py` con la clase `Agente`, carga de `.env` mediante `load_dotenv()`, validacion de `GROQ_API_KEY`, creacion del cliente `Groq` e historial inicial.

Tambien se dejo `main.py` como punto de entrada separado.

## 3. Explicacion de la estructura

**Solicitud:** Explicar detalladamente la estructura utilizada.

**Solucion:** Se explicaron las responsabilidades separadas de `agente.py`, `main.py`, `pyproject.toml`, `.env` y `.venv`, junto con la conveniencia de separar la logica del agente del punto de entrada.

## 4. Error de Git y terminal

**Solicitud:** Resolver el error de la terminal al ejecutar `git push`.

**Solucion:** Se detecto que el proyecto estaba usando por error un repositorio Git ubicado en `C:\Users\mairo`. Se inicializo un repositorio propio dentro del proyecto, se configuro el remoto correcto y se publico la rama `main`.

## 5. Proteccion de la API key

**Solicitud:** Ocultar la API key para que solo el usuario tuviera acceso.

**Solucion:** Se excluyo `.env` mediante `.gitignore`, se elimino del historial local el commit que la contenia, se restringieron los permisos de `.env` al usuario actual de Windows y se verifico que el archivo no estuviera en el repositorio remoto.

## 6. Metodo `responder`

**Solicitud:** Agregar `responder(mensaje)` a la clase `Agente`.

**Solucion:** Se agrego el mensaje del usuario al historial, se llamo a `self.cliente.chat.completions.create()` con el modelo `openai/gpt-oss-120b` y `messages=self.historial`, se obtuvo `respuesta.choices[0].message.content`, se guardo la respuesta con `role: "assistant"` y se devolvio el texto.

## 7. Carpeta independiente de registro

**Solicitud:** Crear una carpeta separada para guardar las solicitudes y soluciones del proyecto, sin vincularla al codigo.

**Solucion:** Se creo la carpeta `registro_solicitudes` sin modificar `main.py` ni `agente.py`.
